Random Name Chooser
================

The Random Name Chooser module takes a list of name and randomly matches each name with another name in the list. Participants can go to a page and view their match.


## Description

After enabling the module go to the settings page (/admin/config/content/random_name_chooser). Toggle enable spouse letter on or off, select the maximum number of name in the list, enter a group name and description that participants will see and note the link to send to participants.

A tab is added to user profile to add names to the list with a link to view view the matches.

Random Name Chooser has an option to assign the same single letter to a couple so that they won't be matched with each other.

Each name needs a personal password (plain text) that they must enter before they can see their match. This makes the process private so others won't be able see their match.

Once the names have been added send a note, with their personal password and the link to the selection page (see settings), to your participants.

The matches are all created when the first person selects their match.

Once the matches have been assigned, adding or removing a new name will clear the match list.

As an option, access to Random Name Chooser can be used by any site user by providing permissions to a role.
